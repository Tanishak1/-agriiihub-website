A mission-driven AgriTech initiative. This repository contains **public-facing marketing content only**.

## Current website
- Responsive single-page website
- English/Hindi language switch
- Vision, mission, journey and community invitation
- Motion with reduced-motion accessibility support
- Static hosting compatible with GitHub Pages

## Preview locally
Open `index.html` in a browser. No build tools or dependencies required.

## GitHub Pages
In repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/(root)`. Once enabled, the expected URL is:
https://tanishak1.github.io/-agriiihub-website/

## Public-content safety checklist
Before publishing any update:
- [ ] No unpublished invention, patent claims, algorithm, architecture, source code, prototype internals or experimental datasets.
- [ ] No confidential MoU, contracts, ownership terms, private discussions, or personal contact details.
- [ ] No unapproved organization logos, affiliations, endorsements or collaborator identities.
- [ ] No unverified claims of launched products, live deployments, government support, funding or partnerships.
- [ ] No third-party images or materials without rights to use them.
- [ ] Verify social links and contact channels before advertising them.
- [ ] Review text in **both** English and Hindi.

## Editorial workflow
1. Draft public copy.
2. Run confidentiality, accuracy and permission checks.
3. Commit changes to `main` after review.
4. Check the live GitHub Pages site on mobile and desktop.
